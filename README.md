# Professional Portfolio

Responsive portfolio website built with HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. An internet connection is recommended for CDN-hosted Bootstrap and fonts.

## Customize before publishing
- Update your name, email, and profile links in `index.html`.
- Replace illustrative project cards with real projects and working links.
- Update the page title and meta description.

## Deploy with GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/(root)`, then save.


Deployment workflow: `.github/workflows/pages.yml` deploys the site to GitHub Pages on pushes to `main`.
